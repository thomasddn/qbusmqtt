# Changelog

## [0.6.0] - 2026-05-13

### Added

- Support for stepper


## [0.5.0] - 2026-04-14

### Changed

- Use new Qbus binaries which expose more outputs and now also support arm64
- Upgrade to Debian trixie


## [0.4.0] - 2024-10-11

### Changed

- Rollback to previous gateway binaries. (#2 / #3)


## [0.3.0] - 2024-06-21

### Changed

- Updated Qbus gateway binaries to support more outputs. The new binaries also support more architectures.
- Now using Debian as base image (instead of Ubuntu).


## [0.2.0] - 2024-01-08

### Added

- Include telnet in image

### Fixed

- Default MQTT port (#1 by @iandroogmans)


## [0.1.0] - 2023-10-20

### Added

- Initial version
